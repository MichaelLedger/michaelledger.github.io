图片来源与许可

最后更新：2026 年 6 月 27 日

多牛单词在测验中展示的图片来自第三方平台。我们仅在 App 内展示图片并标注来源；不声称拥有这些图片的著作权。

测验配图

  • Pexels — 通过官方 API 搜索并下载。许可见 Pexels License。App 在图片右下角标注平台名及摄影师（如有）。
  • Pixabay — 通过官方 API 搜索并下载。许可见 Pixabay License。App 在图片右下角标注平台名及作者（如有）。

例句

  • Tatoeba — CC0 公共领域例句。见 tatoeba.org。
  • Wiktionary / Free Dictionary API — 部分例句来自 Wiktionary，遵循 CC BY-SA。见 CC BY-SA。
  • 其余为 App 生成的儿童友好模板句。
