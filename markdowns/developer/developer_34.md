# Github Copilot Pro for Xcode with Agent Mode - Best Practice

## Environment
macOS 15.4.1
Xcode 16.4
Github Copilot for Xcode 0.35.0

## Agent Mode
*To use Copilot, open Xcode with an active workspace in focus.*

So you can use Copilot in Xcode, you need to have an active workspace. If you don't have one, create a new workspace or open an existing one.

Then add related files at the root of the workspace. This allows Copilot to analyze the context and provide relevant suggestions.

Activate Agent Mode to handle multi-step coding tasks with Copilot.

[Github Copilot Account Settings](https://github.com/settings/copilot)
